# 在线考试

独立于团建转盘的考试页。打开后没有内置题目。监考上传一次题目和答案，考生只填写姓名。评分在服务器上完成。考生浏览器不保存答案。作答记在当前标签页里，刷新不会丢。

## 启动

```bash
cd exam
npm install
npm run dev
```

启动前在当前终端设置环境变量 `PROCTOR_PASSPHRASE`。不要把口令写进文件。

浏览器打开 http://127.0.0.1:5173

同一个链接上有两条入口：点「我是监考」上传题目和答案（需要口令），点「我是考生」只填写姓名。监考口令来自环境变量 `PROCTOR_PASSPHRASE`，不要写进文件。试卷存在服务器上，考生交卷前拿不到答案。

线上同一地址：监考打开后点「我是监考」，考生打开后点「我是考生」。也可以直接用 `#proctor` 和 `#candidate`。

```bash
npm test
npm run build
```

`fixtures/` 里的文件只给测试和手工验收用，应用不会把它们当成默认试卷。

## 空白模板

页面上可以下载三份空白模板：题目 JSON、答案 JSON、Excel。Excel 含两张表。

题目表列：题号、题型、题干、选项A、选项B、选项C、选项D、选项E、选项F、分值、空数。

答案表列：题号、答案、关键词。

可选列「时长」不在空白模板里。写在题目表时，表示整场考试的分钟数。JSON 用 `durationMinutes`。

## 格式

JSON 题目：

```json
{
  "title": "考试名称",
  "durationMinutes": 60,
  "questions": [
    { "id": "1", "type": "single", "stem": "题干", "options": ["选项一", "选项二"], "score": 2 },
    { "id": "2", "type": "multiple", "stem": "题干", "options": ["选项一", "选项二", "选项三"], "score": 4 },
    { "id": "3", "type": "judge", "stem": "题干", "score": 1 },
    { "id": "4", "type": "blank", "stem": "北京是中国的____。", "blanks": 1, "score": 2 },
    { "id": "5", "type": "short", "stem": "题干", "score": 10 }
  ]
}
```

JSON 答案：

```json
{
  "answers": [
    { "id": "1", "answer": "A" },
    { "id": "2", "answer": ["A", "C"] },
    { "id": "3", "answer": true },
    { "id": "4", "answer": ["首都"] },
    { "id": "5", "answer": "参考答案", "keywords": ["关键词1", "关键词2"] }
  ]
}
```

一个空有多个可接受答案时写成嵌套数组，例如 `[["首都","北京"],["中国"]]`。

Excel 题型：单选、多选、判断、填空、简答。多选答案写成 `A,C`。判断填 `对` 或 `错`。填空用 `|` 分隔各空，用 `/` 分隔同一空的多个答案。简答的「答案」是参考答案，「关键词」用逗号分隔。同一个工作簿可以同时包含两张表，也可以分成两个文件。

选择题答案可以是字母、选项原文，或从 0 开始的序号。

页面只渲染文件里出现的题型。

PDF 可以分开上传题目卷和答案卷。大题标题用「一、选择题 / 多选题 / 判断题 / 填空题 / 简答题」。选择题写「每题 N 分」，填空写「每空 N 分」，简答在题末写（N分）。答案卷题号与题目卷一致：选择题写 `1. B`，填空直接写答案并可写「可接受：」，简答写「参考要点」。下划线会被识别成空。简答按参考要点里的关键词比例给分。写「建议用时」不会倒计时，只有「限时 N 分钟」会。
